# Changelog

## 0.2.0 (draft)

- New skills: launch, competitors, client report, PMax guard, author-skill.
- New skill: strategy. Prices each service, asks the owner's figures once, and proposes a launch
  order and budget split the client decides line by line; a service the client skipped is not
  proposed again until its review date or a material change, and then only as a question. Launch
  builds only the services the client accepted and reports each one at 30, 60 and 90 days.
- A whole Search campaign can be staged as one change, created paused.
- The plugin asks the server for the operator tool set, so only the skills' tools are listed.
- New sitelinks, callouts and structured snippets can be staged for approval.

## 0.1.0 (draft)

- House rules: evidence rungs, named ledgers, tool lists, call budgets, the approval path
  (one code for a batch of changes).
